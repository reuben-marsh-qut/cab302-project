# Project Management Software Decision

*Serious Group* Decided to use *Jira* as a Project management software for the CAB302
project. This is because Jira is more popular than competitors, like Trello and Monday.com, for 
software development applications, which is relevant to this.

It is also an Atlassian application, so integrates well with other atlassian products.

Group members also have experience using *Jira*, so there is little learning curve.
