# User Stories

User Story Template

As a ...................... (e.g. Customer, User, Supplier, ...)
I want a ................ (user requirement, product, feature)
so that ............... (user benefit, value)

Acceptance Criteria

Given ............. (pre-condition)
When ............. (Action)
Then ............... (Outcome)

Categories: Mind, Body, Social
Grouping user Stories:
- Goals/Activities/Habits (G)
- Accessibility (A)
- Social (S)
- Basic (B)

1. As a user I want to get notification reminders to complete my activity so that I am held accountable (B)
   - Acceptance Criteria: Given the user has not completed an activity in 12 hours when they open the app then they will receive a notification to complete an activity
2. As a user I want to register an account so that I can have a cross-platform record (B)
    - Acceptance Criteria: Given the user has not registered an account when they open the app then they will be prompted to register an account
3. As a user I want to log in so that I can access my account (B)
    - Acceptance Criteria: Given the user has registered an account and is on the login page when they enter their valid details then they will be looged in
4. As a user I want to change my email and password so that I can update my account information (B)
    - Acceptance Criteria: Given the user is logged into the app in the "account" tab when they enter new details and save the changes then they will have updated details
5. As a user I want to set a username so that I can easily share my account (B)
    - Acceptance Criteria: Given the user is logged into the app in the "account" tab when they enter a new username and save the changes then they will have updated username
6. As a user I want to log out so that my account cannot be accessed by others (B)
    - Acceptance Criteria: Given the user is logged in when the click the "log out" button then they will be logged out of the app
7. As a user I want to navigate the site with <0.3s lag so that I can have a smooth app experience (B)
    - Acceptance Criteria: Given the user is logged in when the user clicks a navigation button then the app will load the next page in <0.3s
8. As a user I want to create community groups so that I can contribute to community goals (S)
    - Acceptance Criteria: Given the user is logged in and on the 'community' page when they click the "create community" button and enter community details then they will create a new community
9. As a user I want to join community groups so that I can contribute to community goals (S)
    - Acceptance Criteria: Given the user is logged in and has been invited to a community when they click "accept invite" then they will join the group
10. As a user I want to open the app to a home page so that I can easily navigate to my desired page (B)
    - Acceptance Criteria: Given the user is logged in when the app opens then they will land on the home page
11. As a user I want to be able to navigate to all main pages (Home, Set Goals, Track Goals, My Activities) in two clicks or less from any page (B)
    - Acceptance Criteria: Given the user is logged in when the attempt to navigate to a main page then they will be able to reach that page in two clicks or less
12. As a user I want to change the colour pallette of the app to high-contrast so that I can easily see the app (if the user is visually impaired) (A)
    - Acceptance Criteria: Given the user is logged in and on the 'accessibility settings' tab when they select the high contrast option then the app will switch to a high contrast colour scheme
13. As a user I want to be able to user screen readers with the app **effectively** so that I can navigate the app easily (if the user is visually impaired) (A)
    - Acceptance Criteria: Given the user is logged in and has a screen reader active when they navigate through the website then the screen reader will read the contents of the page
13. As a user I want to add friends so that I can track my friends and family's progress (S)
    - Acceptance Criteria: Given the user is logged in when they click the "add friend" button on the community page and enter their friends username then they will be added as a friend
14. As a user I want to create goals so that I can achieve my aims (G)
    - Acceptance Criteria: Given the user is logged in and on the 'Goals' page when they click the "set a goal" button and enter goal details then they will create a new goal
15. As a user I want to delete goals so that I can remove goals that I no longer want to track (G)
    - Acceptance Criteria: Given the user is logged in and on the 'Goals' page when they click the "delete a goal" button on a goal then they will delete that goal
16. As a user I want to be prompted to delete and create a new, more achievable goal if I am not making enough progress so that I can still reach achievements (G)
    - Acceptance Criteria: Given the user is logged and has a goal set when they fail to regularly complete related goals then the app will suggest a new goal
17. As a user I want to be informed of my planned activities for the next week so that I can plan my time to complete them (G)
    - Acceptance Criteria: Given the user is logged in and has a goal set when they navigate to the 'Home' page then they will see a table of upcoming activities
18. As a user I want to view my completed activities as a graph display so that I can see my progress (G)
    - Acceptance Criteria: Given the user is logged in when they navigate to the 'Stats' page then they will see a graph of completed acitivties over time
19. As a user I want to mark activities as completed so that I can complete activities (G)
    - Acceptance Criteria: Given the user is logged in when they click the "mark as complete" button on an activity then they will mark that activity as complete
20. As a user I want to collect trophies when I reach certain level milestones so that I can feel a sense of achievement (G)
    - Acceptance Criteria: Given the user is logged in when they collect set amounts of XP then they will collect trophies
21. As a user I want to collect rewards when I reach goal and habit milestones so that I can feel a sense of achievement (G)
    - Acceptance Criteria: Given the user is logged in when they reach habit and goal milestones (i.e. days, completion) then they will receive a reward
22. As a user I want to compare my weekly XP with friends so that others can motivate me (G)
    - Acceptance Criteria: Given the user is logged in when they navigate to the 'Stats' page then they will see a leaderboard comparing their weekly XP to friends
23. As a user I want goals and activities to be recommended for me based on past goals and activities categories so that I can target different aspects of mental health (G)
    - Acceptance Criteria: Given the user is logged in, has completed a goal and is on the 'Goals' page when they click on the "set a goal" button then a modal with suggested goals will appear
23. As a user I want to view my completed goals and activities graphically by category so that I can see what areas of mental health I am targetting (G)
    - Acceptance Criteria: Given the user is logged in when the navigate to the 'Stats' page then they will see a graph displaying their completed goals and acitivities categorised
24. As a user I want to set multiple goals in different categories at once so that I can make more progress (G)
    - Acceptance Criteria: Given the user is logged in and has a goal set when they 'set a goal' which is a different category to existing goals from the 'Goals' page then they will be able to
25. As a user I want new goals to be recommended once I complete a goal so that I can continue to make progress on that area (G)
    - Acceptance Criteria: Given the user is logged when they complete a goal then a new goal should be suggested which extends the previous goal
26. As a user I want habits to be created automatically when I set a goal so that I can make progres towards the goal (G)
    - Acceptance Criteria: Given the user is logged in when they set a goal then a new habit should be automatically created
27. As a user I want to view a description of how a habit relates to my goal when it is created so that I know how I am progressing towards my goal (G)
    - i.e. my goal is to walk for 30 minutes a day for a month, so my habit will be to walk for 30 minutes a day - a habit is the method of tracking goal progress
    - Acceptance Criteria: Given the user is logged in when they click on a habit from the 'Habits' page then they will see a description of how it relates to its goal  
28. As a user I want to be suggested activities outside of my goals so that I can complete extra activities (G)
    - Acceptance Criteria: Given the user is logged in when they navigate to the 'Activities' page then they will see a list of suggested activities unrelated to their goals
29. As a user I want to invite other users to my community goal so that I can complete community goals with friends (G)
    - Acceptance Criteria: Given the user is logged in and on the community page when they click the "invite user" button and enter a user's email then they will be invited to the community
