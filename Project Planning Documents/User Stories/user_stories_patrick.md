# User Stories

User Story Template

As a ...................... (e.g. Customer, User, Supplier, ...)
I want a ................ (user requirement, product, feature)
so that ............... (user benefit, value)

Acceptance Criteria

Given ............. (pre-condition)
When ............. (Action)
Then ............... (Outcome)

Categories: Mind, Body, Social
Grouping user Stories:
- Goals/Activities/Habits (G)
- Accessibility (A)
- Social (S)
- Basic (B)

1. As a user I want to edit my goals so that I can change them if I need to (G)
   - Acceptance Criteria: Given the user is logged in and has a goal when they edit the goal and save it then the goal will be updated

2. As a user I want to pause goals so that I can take a break without deleting my progress (G)
   - Acceptance Criteria: Given the user has an active goal when they pause it then the goal will be paused and progress will be kept

3. As a user I want to resume paused goals so that I can continue working on them (G)
   - Acceptance Criteria: Given the user has a paused goal when they resume it then the goal will become active again

4. As a user I want to view completed goals so that I can see what I have achieved (G)
   - Acceptance Criteria: Given the user has completed goals when they view their goal history then completed goals will be shown

5. As a user I want to filter goals by Mind, Body or Social so that I can find goals I want to work on (G)
   - Acceptance Criteria: Given the user is on the Goals page when they select a category then only goals from that category will be shown

6. As a user I want to view information about a goal before choosing it so that I know what I need to do (G)
   - Acceptance Criteria: Given the user is viewing goals when they click on one then the goal description and details will be shown

7. As a user I want to see how often I need to complete a habit so that I know when to do it (G)
   - Acceptance Criteria: Given the user has a habit when they view it then the habit frequency will be shown

8. As a user I want to view my habit history so that I can see how consistent I have been (G)
   - Acceptance Criteria: Given the user has completed a habit before when they view the habit then previous completions will be shown

9. As a user I want to see which activities belong to a habit so that I know what I need to complete (G)
   - Acceptance Criteria: Given the user is viewing a habit when they open its details then related activities will be shown

10. As a user I want to see which goal an activity is linked to so that I know what I am making progress towards (G)
    - Acceptance Criteria: Given an activity is linked to a goal when the user views the activity then the related goal will be shown

11. As a user I want to complete extra activities outside my goals so that I can do more activities if I want to (G)
    - Acceptance Criteria: Given the user is viewing an extra activity when they mark it as complete then it will be recorded and XP will be given

12. As a user I want to see how much XP an activity gives so that I know what I will earn (G)
    - Acceptance Criteria: Given the user is viewing an activity when they open its details then the XP reward will be shown

13. As a user I want to see when I earn XP so that I know my activity was completed (G)
    - Acceptance Criteria: Given the user completes an activity when it is marked as complete then the XP earned will be shown and added to their total

14. As a user I want my goal progress to update when I complete activities so that I do not need to update it myself (G)
    - Acceptance Criteria: Given the user completes an activity linked to a goal when the activity is marked complete then the goal progress will update

15. As a user I want to see activities due today so that I know what I should complete (G)
    - Acceptance Criteria: Given the user has activities due today when they open the Home page then those activities will be shown

16. As a user I want to filter completed activities by Mind, Body or Social so that I can see my progress in each area (G)
    - Acceptance Criteria: Given the user is viewing completed activities when they select a category then only activities from that category will be shown

17. As a user I want to see how to unlock rewards so that I know what I need to achieve (G)
    - Acceptance Criteria: Given the user is viewing a locked reward when they click on it then the unlock requirement will be shown

18. As a user I want to turn reminders on or off so that I can control my notifications (B)
    - Acceptance Criteria: Given the user is in notification settings when they change the reminder setting then the new setting will be saved

19. As a user I want my progress to save when I close the app so that I do not lose anything (B)
    - Acceptance Criteria: Given the user has goals and progress saved when they close and reopen the app then their data will still be there

20. As a user I want the app to work properly when I resize the window so that I can use different window sizes (A)
    - Acceptance Criteria: Given the app is open when the user resizes the window then the main content and buttons will still be usable
