# User Stories

User Story Template

As a ...................... (e.g. Customer, User, Supplier, ...)
I want a ................ (user requirement, product, feature)
so that ............... (user benefit, value)

Acceptance Criteria

Given ............. (pre-condition)
When ............. (Action)
Then ............... (Outcome)



## User story 1

As a user I want to log in with my username and password so that I can access my own goals and progress.

### Priority - Must Have
### Estimation - TBD
### Acceptance Criteria 
* If I have a registered account, when I enter the correct username and password, then I am taken to the home screen and see my own data
* If I enter an incorrect username and password, when I login , then I will see "Incorrect username or password" and remain on the login screen

## User story 2

As a user i would like to be able to create a long term goal

### Priority - Must Have
### Estimation - TBD
### Acceptance Criteria
* When I choose a goal template and set my own target and deadline, then the goal should be created and appears in my goal list
* When I create a goal, it should be assigned to one of the three categories (mind, body or social)
* If i try to put deadline to past dead it should create an error message.

## User story 6

As a user i want to be able to change my username and password.

### Priority - Should Have
### Estimation - TBD
### Acceptance Criteria
* when I enter a new username that is not taken, my username should be updated and shown on my profile
* If i want to change my password when I enter my current password correctly and a new valid one then the password should be updated

## User story 7

As a user i want to be able to view my completed activities.

### Priority - Must Have
### Estimation - TBD
### Acceptance Criteria
* When I open the history screen, I should see my completed activities listed with the date I completed them and their category
* If I have not completed anything yet, then I should see a message instead of an empty list

## User story 8

As a user I want to see how far along I am on each goal so that I know whether I am on track.

### Priority - Must Have
### Estimation - TBD
### Acceptance Criteria
* When I view a goal, I should see how far along I am as both a number and a percentage of the target
* When I complete a related activity, then my progress on that goal should increase
* If the deadline passes and I have not reached the target, then the goal should be marked as not achieved

## User story 9

As a user I want to build a streak by completing activities on consecutive days so that I am motivated to stay consistent.
### Priority - Should Have
### Estimation - TBD
### Acceptance Criteria
* If I completed the activity yesterday, when I complete it today, then my streak should increase by one
* If I missed yesterday, when I complete it today, then my streak should reset back to one

## User story 10

As a user i would like to have multiple goals concurrently so that i can address multiple aspect of my mental health.

### Priority - Should Have
### Estimation -
### Acceptance Criteria
* When I create another goal while one is already active, then both should stay active and appear in my goal list
* When I complete one goal, then my other goals should not be affected

## User story 11

As a user i would like to be able to earn XP so i can spend them in app.

### Priority - Must Have
### Estimation - TBD
### Acceptance Criteria
* When I complete an activity, then XP should be added to my total and to that activity's category
* When my XP passes a level threshold, then my level should increase and I should be shown a message
* When I am on the home screen, then my current level and XP should be displayed

## User story 12

As a user I would like to get suggestion for new goal based on activities that i have completed the least.

### Priority - Should Have 
### Estimation - TBD 
### Acceptance Criteria
* When I ask for a suggestion, then the goal suggested should come from the category I have completed the fewest activities in

## User story 14

As a user I would like to see my progress over all three categories (mind,body,social)

### Priority - Should Have
### Estimation - TBD 
### Acceptance Criteria
* When I open the comparison view, then I should see mind, body and social shown side by side
* If one category is much lower than the others, then it should be easy to spot without relying on colour alone
* When I complete an activity, then the comparison should update
