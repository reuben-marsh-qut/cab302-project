Overall I think you've done a great job with the UI mockups, most of the issues are minor. I know that your prototypes were made before we even had our first major planning session.

#### General feedback
Some of this is for everyone, I've had some thoughts whilst writing feedback

- We need to consider whether we want to use icons or not
- We need to have rights to use images (wikimedia commons is all creative commons attribution so we could use that)
- Branding needs to be integrated on atleast the signup and login pages, Name - "Rooted", Tagline - "Water your mind"
- We need to actually pin down what pages the application should have. We need to build off [project requirements.md](../../project-requirements.md) and make a more detailed plan?
- We need to consider where we are storing data (ie our SQLite database), Windows has %APPDATA%, Linux has the XDG spec which we should follow and MacOS probably has an equivalent. 
- We need to write down how the user will flow through the application ie Sign Up -> Email confirmation -> Login page -> Home dashboard etc
- Mockups for all the other pages need to be done
- The gamification aspects are almost completely missing from your prototypes
- A centralised UI language/design document wouldn't hurt ie what  what icon set are we using, what css library ([bootstrap](https://getbootstrap.com/)? [shadcn](https://ui.shadcn.com/)?) and do they have JavaFX packages, etc
