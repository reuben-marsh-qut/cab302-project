# Code of Conduct

1. We will treat each other with respect and courtesy
2. If someone is unable to complete a commitment (such as attending the weekly meetings or finishing a task) they should inform the team (via the Instagram group chat) as soon as possible so that a workaround can be found.
3. We will meet twice a week, in person during the Monday 4-6pm tutorial and online in an Instagram voice call at 3pm on Fridays. 

## Conflict Resolution
We will first try to resolve the conflict ourselves, if that fails we will escelate to the Tutors within our tutorial and failing that the Unit Coordinator.
